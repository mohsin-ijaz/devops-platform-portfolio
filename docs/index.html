Kubernetes Platform

AWS EKS Terraform platform

Problem
Reusable EKS infrastructure with controlled access, networking, delivery roles, and environment separation.
Architecture
Terraform modules for VPC, EKS, node groups, ECR, bastion, transit/VPN, security groups, endpoints, and GitLab CI OIDC.
Engineering decisions
Uses access entries, IRSA/OIDC patterns, managed node groups, Bottlerocket settings, and explicit environment tfvars.
Implementation
Includes live network/workload stacks, backend bootstrap, scripts, and modules for cluster and delivery primitives.
Operational value
Shows how production clusters can be built with repeatable boundaries, auditable CI access, and multi-account design.

SRE Observability

LGTM stack and anomaly detection

Problem
Make production systems observable enough to debug, alert, manage cost, and control high-cardinality telemetry.
Architecture
Grafana, Loki, Tempo, Mimir, Prometheus, Alloy, dashboards, alert rules, internal load balancers, and telemetry ML scoring.

Implementation

Operational value
Shows how observability can become an operating layer for reliability, cost, and faster incident investigation.

Platform architecture

A production platform shape, not a pile of examples

Reusable infrastructure

Cluster, network, IAM, storage, registry, and managed service modules are separated so environments can evolve without rewriting the platform.

Delivery guardrails

OIDC-based CI access, manual production gates, plan artifacts, Helm atomic deploys, Kustomize overlays, and Argo CD patterns keep changes reviewable.

Operating feedback

Dashboards, alerts, audit logs, FinOps rules, tracing, and anomaly detection make reliability visible before incidents turn into guesswork.

Reliability and SRE

Operational signals that help teams act

High-cardinality telemetry

Alloy and Loki processing move expensive fields into structured metadata, drop noisy traffic, and keep labels useful for fast query paths.

Mimir query performance

Mimir values tune query sharding, cache behavior, scheduler capacity, retention, tenant boundaries, and remote-write ingestion.

FinOps signals

Recording rules estimate current cost, optimized cost, savings, overprovisioning, and right-sizing opportunities by cluster, namespace, and workload.

Audit response

Kubernetes audit policy and Loki alert rules highlight exec, port-forward, RBAC changes, anonymous access, manual token creation, and secret reads.
